Documentation utilisateur

EduPaie - Gestion des paiements scolaires

1. Présentation

EduPaie est une application de bureau pour gérer les paiements des élèves : inscription des élèves, enregistrement des paiements, suivi des soldes, historique et reçus PDF. Les données sont stockées localement sur l'ordinateur.

2. Navigation

La barre latérale à gauche donne accès aux six sections :

  • Tableau de bord : indicateurs clés (élèves, montants encaissés et restants, non soldés) et liste des élèves filtrable par statut ;
  • Élèves : ajout, modification, suppression, recherche et filtre par classe ;
  • Encaissement des paiements : choix de l'élève, montant, date et mode de paiement ;
  • Historique : paiements d'un élève et réouverture des reçus ;
  • Reçus : recherche et ouverture des reçus PDF générés ;
  • Paramètres : nom de l'établissement, logo et couleur de marque.

3. Ajouter un élève

  1. Ouvrez la section Élèves ;
  2. Renseignez le nom, le prénom, la classe (liste déroulante du système togolais, modifiable), l'année scolaire et le montant total ;
  3. Cliquez sur Ajouter l'élève.

Astuce : la touche Entrée dans le champ de recherche lance directement la recherche.

4. Enregistrer un paiement

  1. Ouvrez Encaissement des paiements ;
  2. Sélectionnez l'élève : le solde restant s'affiche ;
  3. Indiquez le montant, la date et le mode de paiement (espèces, chèque, virement, mobile money) ;
  4. Cliquez sur Enregistrer le paiement : le reçu PDF est généré automatiquement.

Le statut de l'élève évolue automatiquement : Non payé, Partiellement payé ou Soldé.

5. Consulter et réimprimer un reçu

Depuis Historique, sélectionnez un élève puis un paiement, ou depuis Reçus recherchez le numéro de reçu (ex. REC-2026-0001). Le bouton Ouvrir le reçu affiche le PDF.

6. Personnaliser l'application

Dans Paramètres vous pouvez :

  • Changer le nom de l'établissement (affiché dans l'application et sur les reçus) ;
  • Ajouter le logo de l'école ;
  • Choisir la couleur de marque.

7. Sauvegarde des données

Les données se trouvent dans le dossier database/edupaie.db et les reçus dans receipts/, à côté de l'application. Copiez ces dossiers pour sauvegarder ou transférer l'application vers un autre poste.

8. Dépannage

  • L'élève ne peut pas être supprimé : des paiements sont déjà enregistrés pour lui ;
  • Le montant dépasse le solde : le paiement est refusé pour éviter les trop-perçus ;
  • Un reçu est introuvable : vérifiez le numéro dans la section Reçus.
